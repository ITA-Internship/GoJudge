# ADR-001: Go version pin

* **Status:** Provisional
* **Date:** 2026-11-03
* **Authors:** Pair D
* **Depends on:** DEC-14, MA-02

## Context
Pin of the specific Go version is required for the project to ensure reproducible builds across development environments.

## Decision Driver & Approval Condition
- This decision depends on **DEC-14**
- This decision is **Provisional** and is **NOT approved until confirmed by MA-02**.

## Considered Options
* Pin to the latest stable Go release (Go 1.27.3)
* Pin to a different explicitly selected Go release.

## Decision
Provisional choice: pin the project to Go 1.27.3, the latest stable release at the start of Sprint 1. 
This version is selected to ensure consistent and reproducible builds across development environments.

## Consequences
Consistent toolchain across developer machines and build pipelines.
