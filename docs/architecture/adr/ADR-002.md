# ADR-002: Local cluster tool selection

* **Status:** Provisional
* **Date:** 2026-11-03
* **Authors:** Pair D
* **Depends On:** DEC-06, MA-02

## Context
A standardized cluster tool is required for developers to run and test services locally under Kubernetes conditions.

## Decision Driver & Approval Condition
- This decision depends on **DEC-06**
- This decision is **Provisional** and is **NOT approved until confirmed by MA-02**.

## Considered Options
* Local cluster tooling option selected in DEC-06

## Decision
Provisional choice to adopt the local cluster tool defined in DEC-06 for local development environment setup.

## Consequences
Standardized development runtime environment across the team.
